# iPhone Model Photos Directory

Place your real iPhone model photos in this directory (`assets/images/`).

### Supported Naming Convention

| Model | Recommended Filename | Fallback Filename |
| :--- | :--- | :--- |
| **iPhone 11** | `iphone-11.webp` | `iphone-11.png` |
| **iPhone 12** | `iphone-12.webp` | `iphone-12.png` |
| **iPhone 13** | `iphone-13.webp` | `iphone-13.png` |
| **iPhone 14** | `iphone-14.webp` | `iphone-14.png` |
| **iPhone 15** | `iphone-15.webp` | `iphone-15.png` |
| **iPhone 16** | `iphone-16.webp` | `iphone-16.png` |
| **iPhone 16 Plus** | `iphone-16-plus.webp` | `iphone-16-plus.png` |
| **iPhone 16 Pro** | `iphone-16-pro.webp` | `iphone-16-pro.png` |
| **iPhone 17 Pro Max** | `iphone-17-pro-max.webp` | `iphone-17-pro-max.png` |

### Automatic Fallback
- If a photo file is present in this folder, the website will display it automatically.
- If a photo is not yet uploaded, the website seamlessly displays the high-resolution vector SVG device preview with zero broken image icons or layout shifting.
